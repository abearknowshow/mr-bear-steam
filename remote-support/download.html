Let the Mac drive.

This separate support app lets Codex read controls and operate Bear Steam, Mr. Steam and Chrome. The working Bear 0.12 and original Mr. Steam stay installed.

Install Bear Remote Support

  1. Install and open Bear Remote Support.
  2. Tap Open Accessibility settings. Enable the separate Bear Remote Support service, then return to the app.
  3. Tap Start support · 30 minutes. Tell Codex it is ready.

A visible Stop support button ends access immediately. This service requests screen-content reading and gesture control; that is different from Bear Steam's display-only service. It sends visible controls and text to this Mac, excluding password fields. It does not stream screenshots, read private app files, or run shell commands.

Leave Mr. Steam running. Do not force-stop it. Physical panel compatibility is the remaining check after offline emulator tests.
