Let the Mac see and drive.

Bear Remote Support 0.2 lets Codex see this screen and tap anywhere on Bear Steam, Mr. Steam, Chrome and Settings. The working Bear and original Mr. Steam stay installed.

Install Bear Remote Support 0.2

  1. Install the update and open Bear Remote Support. The Accessibility setting from 0.1 normally stays on; if the app shows Open Accessibility settings, turn the Bear Remote Support service back on and return.
  2. Tap Start support · 2 hours.
  3. Android asks whether Bear Remote Support may start capturing everything on the screen. Tap Start now.
  4. Tell Codex it is ready.

A visible Stop support button, the Stop support notification action, locking the screen, or turning the service off ends access immediately. Sessions end after 2 hours.

Screen images are small, compressed and kept only in the Mac relay's memory. Nothing is sent while a password field is visible, and installers, permission screens and Accessibility or security settings are never sent or operated remotely. Those stay yours to tap.

Leave Mr. Steam running. Do not force-stop it.
